# Global Rules

- Ưu tiên thay đổi nhỏ, an toàn, dễ review.
- Tự động tạo nhánh, commit và đẩy (push) lên GitHub khi hoàn thành task:
  - Sử dụng tiền tố nhánh `feat/<tên-tính-năng>` cho các tính năng mới.
  - Sử dụng tiền tố nhánh `fix/<tên-lỗi>` cho các sửa lỗi (bug fixes).
  - Format commit message: `feat: mô tả ngắn` hoặc `fix: mô tả ngắn` (Conventional Commits).
- Không hardcode secret/token/key.
- Không sửa lấn sang module không liên quan task.
- Có trade-off thì ghi rõ trong handoff.
