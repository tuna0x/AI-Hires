# Agent Rules Hub

Thư mục này là nơi tập trung toàn bộ rule nội bộ theo chủ đề để team dễ quản lý.

## Cấu trúc

- `agent/global.md`: quy tắc chung toàn dự án
- `agent/backend.md`: quy tắc riêng backend
- `agent/frontend.md`: quy tắc riêng frontend
- `agent/review.md`: quy tắc viết tài liệu review/kế hoạch

## Lưu ý quan trọng

Các coding assistant thường tự nhận diện rule theo file tên `AGENTS.md` theo scope thư mục.  
Vì vậy bộ file trong `agent/` dùng để quản trị tập trung cho con người/team, còn `AGENTS.md` theo từng scope vẫn cần giữ để agent tự áp dụng đúng.
